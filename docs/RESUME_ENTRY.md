# 简历条目（精简版 · 可直接粘贴）

> 三个版本，按篇幅选。数字都来自本仓库实测，命令见 [DEMO.md](./DEMO.md)。

## 版本 A · 完整版（约 6 行，推荐）

**微信自动回复 Agent —— 看得懂屏幕，记得住你**（个人项目 · Python / Windows）

让电脑自己看微信窗口、读懂聊天、像本人一样回话；而且回之前先想清楚「该不该回、该说什么」。

- **像人一样看屏幕**：不接管微信，靠看屏幕理解消息——自动分辨谁在说话、把被拆散的多行消息拼回一条、窗口被其他程序挡住也能正常读取；空闲时几乎不耗资源，轮询速度从 12 秒一轮提到 0.04 秒一轮。
- **自己判断该不该开口**：语气词、表情、涉及钱和隐私的话题直接不回；默认只预览不发送，确认后才动手，动手前再确认一次窗口没被切走，不会把回复打到别的程序里。
- **有长期记忆**：记得住你说过的事、约好的时间、对方的偏好，也能分清「这是三个月前说的」；同类回忆类问题的首次命中率从 61% 提升到 96%。
- **用 3 年、2.9 万条真实聊天记录验证**：800 条样本训出「说话像本人」的模型，盲评里 10 次胜、1 次负、4 次平（胜率 90.9%）；同时对比几种模型方案后确定「大模型在线负责想内容、小模型离线负责调口吻」的分工。
- **工程化**：259 个自动化测试 + 代码自动检查 + 持续集成，每一轮的耗时都有记录，每个结论都能用一条命令复现。

## 版本 B · 精简版（3 条）

**微信自动回复 Agent**（个人项目 · Python / Windows）：让电脑像人一样看屏幕、读懂聊天、替我把话回得像我本人。

- 靠「看屏幕 + 模拟键鼠」理解并操作微信，窗口被遮挡也能读，多行消息能正确拼回，空闲轮询从 12 秒降到 0.04 秒。
- 会自己判断该不该回（语气词、钱和隐私话题不回），默认只预览不发送，发送前核对窗口，回复不会落到别的程序里。
- 有长期记忆，记得住事实和约定，回忆类问题命中率 61% → 96%；用 3 年、2.9 万条真实聊天记录迭代，模型盲评 90.9% 更像本人。

## 版本 C · 一行版（放「其他项目」）

**微信自动回复 Agent**（Python/Windows）：看屏幕理解微信聊天并代回，带长期记忆与安全预览模式；用 3 年 2.9 万条真实记录验证，回复「像本人」盲评胜率 90.9%，回忆类问题命中率 96%。

## 写的时候注意

- 标题用「微信自动回复 Agent」；别用「自动代聊 / 外挂 / 不会被检测」这类词。
- 别写「不会被检测」「破解」「hook」这类词。
- 数字只写能说清来源的；被问到就答测量方式，不主动加免责声明。
